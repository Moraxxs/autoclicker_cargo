# 📌 Короткая инструкция: 
## Как запустить (Windows Chrome)

### 1. Откройте сайт
```
Сайт → войдите → откройте страницу бронирования
```

### 2. Откройте консоль
```
Нажмите F12 → вкладка Console
```

### 3. Вставьте код
```
Скопируйте весь код v3 → вставьте в консоль → Enter
```
## Перед первым запуском может потребоваться написание в консоль "allow pasting"
---

## 📌 Как сделать сниппет (чтобы не копировать каждый раз)

### Windows:
1. **F12** → вкладка **Sources** (Источники)
2. Слева найдите **Snippets** → правый клик → **New snippet**
3. Назовите: `slot-watcher`
4. Вставьте код → **Ctrl+S** (сохранить)
5. Запуск: правый клик на сниппете → **Run**


## 🎮 Как пользоваться

### После запуска появится виджет:

| Кнопка | Что делает |
|--------|------------|
| **Старт** | Начать проверку слотов |
| **Стоп** | Остановить проверку |

### Вкладки:
- **Обзор** — статистика и свободные слоты
- **Даты** — выбрать какие дни отслеживать
- **Журнал** — история событий
- **Настройки** — параметры

---

## ⚙️ Важные настройки

### Вкладка «Настройки»:

| Настройка | Рекомендация | Описание |
|-----------|-------------|----------|
| **Интервал** | 15-40 сек | Как часто проверять |
| **Авто-клик** | ✅ вкл | Автоматическая бронь |
| **Задержка клика** | 300-500 мс | Пауза перед кликом |
| **Звук** | ✅ вкл | Звуковое оповещение |
| **Уведомления** | ✅ вкл | Системные уведомления |

---

## ⚠️ ВАЖНО!

### Про интервал проверки:
- **1-2 сек** — ❌ ЗАПРЕЩЕНО! Блокировка аккаунта/IP
- **5-10 сек** — ⚠️ Рискованно
- **15-30 сек** — ✅ Безопасно

### Про авто-бронь:
- Может нарушать правила сайта
- Используйте на свой риск!

---

## 🔧 Если не работает

1. **Обновите страницу** (F5)
2. **Проверьте консоль** (F12 → Console) — красные ошибки
3. **Вставьте код заново**
